# RunLens Phase 0 Implementation Plan

> 按用户明确授权在本会话逐项实施；Phase 0 验收后暂停，等待确认 Phase 1。

**Goal:** 建立可以在 Python 3.11 下安装、启动和测试的最小项目。

**Architecture:** 使用 src 布局，将 Python 包与根目录 Streamlit 入口分开。
当前只提供版本信息和初始化说明，不创建尚未实现的算法模块。

**Tech Stack:** Python 3.11、venv、pip、setuptools、Streamlit、pytest、ruff。
后续分析依赖在 pyproject.toml 中以可选 analysis 依赖组声明。

## 方案选择

- 采用标准 venv + pip + src 布局：符合任务文档，隔离本机其他 Python。
- 平铺代码：初期略简便，但不利于后续独立安装和测试核心算法。
- Conda / Docker：当前无需引入这些额外工具。

仓库已初始化且尚无提交；直接在现有目录开发，保留原始 prompt.md。
需求已明确，不再增加设计确认环节。本轮范围依据任务文档第十八节。

## Task 1：需求与阶段控制

Create: PRD.md、TASKS.md。

整理产品目标、v0.1 范围、非目标、算法约束和分阶段验收。
TASKS.md 的验证状态必须在真实运行后更新。

## Task 2：可安装项目与最小测试

Create: pyproject.toml、src/runlens/__init__.py、src/runlens/__main__.py、
tests/test_smoke.py、app.py。

先编写包导入和命令行版本输出的测试，运行观察未实现时的失败；
再实现版本信息、命令行入口与仅含初始化说明的 Streamlit 页面。
测试运行命令：python -m pytest。

## Task 3：安装、开源与 CI 配置

Create: README.md、docs/USER_GUIDE.md、examples/README.md、LICENSE、
.gitignore、.gitattributes、.github/workflows/tests.yml。

提供 Windows 与 Linux/macOS 的安装和启动命令。演示数据从 Phase 1
开始提供，不伪造示例结果。CI 使用 Python 3.11，在三个系统执行
安装、pytest、ruff；尚未运行的 CI 不标记为通过。

## Task 4：真实验收与 Git

建立 Python 3.11 虚拟环境，安装 .[dev]；运行 pytest、ruff check、
ruff format --check、pip check，并检查 Streamlit 启动。
记录真实环境与结果。提交前检查待提交文件与 Git diff，避免包含
虚拟环境、私有数据、密钥和下载的工具。只做本地提交，不推送或发布。
