# RunLens Phase 1 Implementation Plan

**Goal:** 实现 CSV → 显式字段/时间单位映射 → 质量报告 → 信号查看的最小闭环。

**Architecture:** `schemas.py` 定义配置与结果；`io.py` 负责严格 CSV 解析、
数值转换和相对时间；`quality.py` 分析原始行序；`plotting.py` 仅生成 Plotly
图形。`demo.py` 提供固定种子的合成数据。Streamlit 入口调用独立核心函数。

**Tech Stack:** Python 3.11、pandas、NumPy、Streamlit、Plotly、pytest、ruff。
Phase 1 将 pandas/NumPy/Plotly 移入运行依赖；SciPy/scikit-learn 留待后续。

## 设计与范围

使用单入口的“数据概览 / 信号浏览”切换，先不创建尚无功能的页面。
相较于将解析与绘图塞进界面，独立模块允许针对精度与质量规则直接测试；
相较于完整五页架构，当前结构便于小步验收。

时间单位必须显式选择，不根据数值大小猜测。CSV 按字符串读取；时间戳
使用十进制数先减去首个有效值，再转为相对秒。相邻间隔独立求差。
混合缺失/非法时间戳保留原始行并报告；全部时间戳无效时给出错误。
禁止静默排序、删除原始行、填补缺失值或重采样。

采样间隔基准为有效相邻对中正间隔的中位数；大间隔 > 基准 × factor，
短间隔 < 基准 / factor，factor 默认 3，用户可调且须大于 1。
重复时间戳包括非相邻重复；逆序只检查原始相邻有效对。
所有结论都只表示观测的数据质量问题，不表示真实传感器丢帧或故障。

绘图在无效值、原始行不连续、逆序、重复与异常间隔处断开，避免跨中断
连线。每个通道单独纵轴。最多展示 8 个通道、20,000 行、50 个质量标记，
超出时提示缩小范围；不静默抽稀。CSV 限制为 20 MiB、100,000 行、64 列。

## Task 1：核心测试先行

Create: tests/test_io.py、tests/test_quality.py、tests/test_demo.py。

覆盖空/畸形 CSV、缺失/重复字段、UTF-8 BOM/CRLF、EuRoC 风格表头、
s/ms/us/ns 单位、超大整数纳秒精度、非法时间戳、NaN/Inf、单样本、
重复/逆序/大/短间隔、常数与全无效信号、确定性合成数据和注入标签。
先运行 pytest 确认因模块未实现而失败，再实现对应模块并修复失败。
