# RunLens Phase 3 Implementation Plan

**Goal:** 交付 MAD、Isolation Forest、可定位候选区间与导出，并使用真实机器人记录测试。

**Architecture:** 新增独立 anomaly.py；schemas.py 添加不可变检测配置/结果。
检测单位为原始采样行：MAD 对每通道检测，IF 对同一行的多通道向量联合检测。
参考区间和检测区间必须不重叠；参数、基准统计、有效拟合数、分数方向和跳过原因
均保留。app.py 增加异常检测表单及区间定位，plotting.py 添加候选高亮。

**Tech Stack:** Python 3.11、NumPy、pandas、SciPy、scikit-learn、Plotly、Streamlit、pytest。
scikit-learn 加入运行依赖；版本 0.0.4。保持原有模块接口和用户文件。

## 设计与范围

- MAD 分数 = abs(x−训练中位数) / max(1.4826×训练 MAD, 显式最小尺度)，
  默认阈值 3.5，严格大于阈值才标为候选。NaN/Inf/无效时间戳不评分。
  MAD 与尺度均为零时禁用该通道并说明原因，避免除零及量化信号无意义误报。
  最小尺度单位同输入通道；原始量纲不同的通道应单独配置或分批检测。
- IF 使用用户选定原始通道作为多变量输入，不拼接泄漏窗口。按训练列的
  最大绝对值进行数值缩放，缩放仅在参考区间拟合；不补缺失值、不裁剪极端值。
  至少 16 个完整有限训练行，全部训练通道为常数时不输出虚构候选。
  固定随机种子、单 CPU worker；分数 = −decision_function，阈值 0，
  分数越高越异常，严格大于 0 为候选。contamination 是训练阈值参数，非故障概率。
- MAD 至少 5 个有效参考样本/通道；短/无效通道保留状态。
  参考区间由用户确认用途，程序不保证其正常；默认先后分割不等同于真实正常标注。
- 只合并同方法/通道、相邻原始行的候选；无效/正常行、重复/逆序时间或
  超出质量间隔阈值均打断区间。记录峰值分数、阈值、规则、行号与时间。
  不跨越时间轴问题绘制连续阴影；多通道 IF 候选不解释为单轴根因。
- 每次结果保存完整配置、原始数据指纹和计时，支持候选 CSV、逐行分数 CSV、
  配置 JSON。表格/图形有明确显示上限，不创建 Phase 4 的完整报告或比较指标。
- 真实数据优先：核查官方来源与许可，使用小型可再分发机器人力/力矩记录作为
  离线回归样本；原样测试与显式扰动副本测试分开。没有原始时间戳的数据明确说明
  时间轴构造约定，不把推定时间用于真实采样质量或物理频率结论。
  EuRoC 下载受限时如实记录，不阻塞核心开发，不伪造真实 IMU 测试。
