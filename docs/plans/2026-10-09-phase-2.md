# RunLens Phase 2 Implementation Plan

**Goal:** 添加可验证的窗口特征、三轴模长、FFT/Welch 及特征 CSV 导出。

**Architecture:** 在 schemas.py 增加不可变窗口/频谱配置与结果对象，新增
features.py 作为独立数值模块。保留 Phase 1 数据结构和质量规则；app.py
增加特征分析视图，计算由表单触发并使用有上限的会话缓存。

**Tech Stack:** Python 3.11、NumPy、pandas、SciPy、Plotly、Streamlit、pytest、ruff。
SciPy 移入运行依赖，scikit-learn 留待 Phase 3；版本改为 0.0.3。

## 设计选择与数值约定

- 按原始样本行滑动，窗口长度/步长均为样本数。默认丢弃不完整尾窗，
  用户可选择保留；不足一窗且不保留尾窗时返回带表头的空结果。
- 时域统计是样本统计，不是时间加权统计：mean/std/variance/RMS/min/max/
  peak-to-peak/median/IQR，std 与 variance 使用 ddof=0，IQR 使用线性分位数。
  NaN/Inf 可选择 omit 或 propagate，均记录有效/无效计数，不修改原始行。
- 模长需要明确三个不同数值通道，使用稳定的 hypot 运算，新通道不覆盖
  原始轴；名称冲突报错。派生值存在无效轴时为 NaN。
- 频谱要求至少两个有限信号/时间样本且时间严格递增；每个正间隔与
  中位数相对偏差不超过可配置容差（默认 1e-6，上限 0.05）。不做插值。
  较大容差意味着近似等间隔假设，界面显示容差与实测最大偏差。
- FFT 使用 SciPy rfft、矩形窗、单边幅度归一化，DC/Nyquist 不翻倍。
  Welch 使用显式周期 Hann、50% 重叠、density、均值平均，nperseg 不超过
  实际样本数。默认整段去均值，Welch 不再次逐段去趋势。
- 主频为非 DC FFT 最大幅度；全零/常数去均值后无主频和谱质心。
  PSD 积分使用 sum(PSD) × Δf，单位为信号单位²；谱能量估计为
  PSD 积分 × (N/fs)，单位为信号单位²·s，不宣称机械物理能量。
- 每窗频域失败只标记原因，时域仍保留；不输出虚构频率。
  数值无法表示的特征标记溢出并留空。最多 50000 条窗口×通道结果；
  累计窗口处理量最多 2000 万个信号值，避免高度重叠的大窗口长期阻塞 CPU。
