# RunLens 技术交底书结构提纲

这是课程材料的组织结构，记录实际方案与实现。未进行专利现有技术检索，不提出新颖性、
创造性或可授权结论。FFT、Welch、MAD、Isolation Forest 均按现有方法描述。

## 1. 名称、用途与技术领域

名称建议：一种机器人离线时序数据分析与异常候选证据导出工具。
用途：研究和研发记录的 CSV 检查、特征分析、候选定位及可重复报告。
不将用途写为经过验证的硬件诊断、故障根因识别或实时安全控制。

## 2. 背景技术与具体问题

描述实际处理难点：绝对时间精度、非规则采样、不透明插值、无效值、参考泄漏、
不同层级标签误用、旧结果混用和缺少复现信息。只说明问题，不声称不存在同类工具。
如需现有技术比较，另行完成有日期、检索范围和来源的检索记录，不能用本提纲代替。

## 3. 实际实现的技术方案

| 步骤 | 输入/处理 | 输出/约束 |
| --- | --- | --- |
| 导入 | 有界 UTF-8 CSV、显式时间单位/通道 | 保留原始表和样本行 |
| 时间转换 | Decimal 求相对差及原始相邻间隔 | 不排序、不插值、状态分类 |
| 质量检查 | 重复、逆序、间隔倍数、无效值 | 带行号、规则和阈值的证据 |
| 特征 | 样本窗口、稳定模长、时域；采样合法才频域 | 参数、计数、频域拒绝原因 |
| 候选检测 | 不重叠参考/检测范围，MAD/IF 仅参考拟合 | 分数、状态、候选区间 |
| 评价 | 明确点/完整事件真值和覆盖条件 | 混淆矩阵、指标、排除原因 |
| 报告 | LF 数据指纹及导入映射核对 | JSON/Markdown/HTML 与完整 CSV |

将方案图与 [架构](ARCHITECTURE.md) 对应，交代异常数据的失败路径，而非只有正常路径。

## 4. 实施例与可观察效果

实施例一：重复/逆序/异常间隔及无效值，保留原始测量而不隐式修复。
实施例二：解析常数/正弦验证特征，公开 LP1 真实时域分析。
实施例三：固定参考与留出事件的 MAD/IF，逐单位预测可回算指标。
实施例四：同一 CSV 更换单位或通道时，报告拒绝旧来源结果。
使用实际实验记录，包含误报和拒绝计算；效果仅限这些运行与测试支持的范围。

## 5. 参数、替代实现与限制

列明默认参数、容量、零 MAD 行为、数值范围、缓存和报告预览限制。
