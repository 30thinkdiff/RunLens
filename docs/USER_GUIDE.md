# RunLens 中文使用指南

## 当前能做什么

Phase 5（0.0.6）已提供 CSV 导入、时间戳/通道/单位映射、基础质量报告、
Plotly 曲线、滑动窗口特征、三轴模长、FFT/Welch、MAD/Isolation Forest、
候选区间定位与特征/候选/分数 CSV、检测配置 JSON 导出。
默认内置 Synthetic Data，可直接演示，也可下载 CSV、注入标签与生成配置。
使用离线真实机器人力/力矩记录进行固定实验，导出指标、预测和 JSON/Markdown/HTML 报告。
请先在项目根目录执行以下命令。

## Windows PowerShell

确认使用 CPython 3.11，而不是其他版本或 MSYS2 Python：

```powershell
py -3.11 --version
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m runlens --version
.\.venv\Scripts\python.exe -m streamlit run app.py
```

若没有可用的 `py` 启动器，用 Python 3.11 的实际路径代替 `py -3.11`。
本工作区若已配置 `.tools/python311/python.exe`，可用项目内环境：

```powershell
.\.tools\python311\python.exe --version
.\.tools\python311\python.exe -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

`.tools/` 和 `.venv/` 不进入 Git，其他人克隆仓库后需自行安装 Python 3.11。
使用虚拟环境解释器的完整相对路径，无需激活环境或修改 PowerShell 执行策略。
IDE 解释器选择 `.venv/Scripts/python.exe`。

## Linux / macOS

准备好 Python 3.11、pip 和 venv 后执行：

```bash
python3.11 --version
python3.11 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m runlens --version
.venv/bin/python -m streamlit run app.py
```

部分 Linux 发行版需要通过其软件包管理器安装对应的 venv 组件。
macOS 使用适配本机架构的 Python；本项目未在本机验证 Intel/Apple Silicon。

浏览器打开 Streamlit 输出的本地 URL（默认 `http://localhost:8501`）。

## CSV 分析操作

1. 启动后默认使用 **Synthetic Data**，查看样本数、估计采样频率和质量证据。
2. 左侧选择“上传 CSV”，上传带表头的 UTF-8 文件（支持 BOM、CRLF/LF）。
3. 指定时间戳列和至少一个数值通道；时间列不能同时作为信号通道。
4. 显式选择 `s`（秒）、`ms`（毫秒）、`us`（微秒）或 `ns`（纳秒）。
   不根据大小自动判断单位。时间戳应是数值，不支持日期/ISO 文本。
5. “数据概览”查看时间戳质量、采样间隔、各通道统计和检测依据。
6. 切到“信号浏览”，选绘图通道，拖动时间范围；Plotly 支持缩放与悬停。
   详情表保留原始字段和 0 起始样本行号。

普通 CSV 示例：

```csv
timestamp,accel_x,gyro_z
0,0.1,0.01
0.01,0.2,0.02
0.02,0.3,0.01
```

这段数据应选择 `timestamp`、`s` 和 `accel_x`/`gyro_z`，估计频率为 100 Hz。

EuRoC MAV 的 IMU CSV 导入：从 [官方数据集页](https://projects.asl.ethz.ch/datasets/euroc-mav/)
取得数据后，上传解压目录中的 `mav0/imu0/data.csv`。保留带 `#` 的表头，
手动选择 `#timestamp [ns]`（或文件中的实际名称）以及角速度/加速度通道，
时间单位选择 `ns`。仓库没有捆绑 EuRoC；本轮官方端点连接超时或访问受限，
尚未运行真实 EuRoC IMU 实验。当前真实回归数据使用小型 UCI 机器人力/力矩记录。

## 质量规则与解释

- 起点为首个有效原始时间戳。内部先用十进制数求差，再转相对秒，
  防止直接将绝对纳秒时间转为浮点而损失精度；原始字段仍保存。
- 不修改原始行序，不自动排序、删除行、填补 NaN、插值或重采样。
- 频率 = `1 / median(有效原始相邻对的正间隔)`；缺失/非法时间戳打断相邻关系。
- 大间隔 > 中位数 × 阈值倍数；短间隔 < 中位数 / 阈值倍数（默认 3）。
  倍数必须大于 1。大间隔只说明观测到时间异常，不能确认真实丢帧。
- `duplicate_timestamp` 表示数值时间戳曾出现过（包括非相邻重复）；
  `reverse_timestamp` 表示原始相邻有效时间戳差小于零。
- NaN/空值、Inf 和非数值内容分别计数；通道统计只使用有限值，
  标准差采用总体定义 `ddof=0`；至少两个相同有限值才标注常数通道。
- `row_start` / `row_end` 是 0 起始的样本行号，端点都包含；
  并非 CSV 物理行号（引号内换行和空行可能影响物理行号）。
- 全部时间戳无效、无数据行、重复/空列名或字段数不一致会显示错误；
  混合无效时间戳仍保留并报告，但这些行不能定位到时间轴。

正常静止信号也可能是常数；输入中大部分间隔异常或采样率分段变化时，
中位数基准可能无法代表期望频率。系统不推断机器人故障根因。

## 窗口特征与 CSV 导出

1. 切到“特征分析”，设置窗口长度与步长，单位均为**样本数**。
   默认 256/128；窗口从原始第 0 行开始，按步长前进，不按时间重新分组。
2. 默认只保留完整窗口；可勾选保留尾部不足长度的窗口。
   数据不足一窗时默认返回空结果，仍可下载含表头的 CSV。
3. 选择无效值策略：`omit` 在时域统计中排除 NaN/Inf，并记录数量；
   `propagate` 遇到任何无效值就把统计指标留空。两者均不改变原始数据。
4. 可增加三轴模长，明确选择三个不同通道与不冲突的名称。模长为
   `sqrt(x²+y²+z²)`，使用稳定计算；任一轴无效则模长无效，原始轴仍保留。
   三轴应具有相同单位且对应同一物理量；不要把加速度和角速度混合求模长。
5. 点击“计算窗口特征”；计算量较大时等待完成。修改表单后必须再次提交，
   页面结果与 CSV 显示的是最后一次成功提交的参数。
6. 查看前 1000 条记录和特征趋势；“下载特征 CSV”包含完整结果。
   更换 CSV、时间列、单位或分析通道会清除旧结果，需重新计算。

指标 `mean/std/variance/rms/min/max/peak_to_peak/median/iqr` 分别为均值、
总体标准差、总体方差、均方根、最小值、最大值、峰峰值、中位数和四分位距。
`std/variance` 的 `ddof=0`；分位数使用线性插值，IQR = Q75 − Q25。
这些是**样本等权统计**，不规则时间戳下不代表时间加权统计。
无有限样本时统计留空；单个有限样本的总体标准差/方差为零。
超出可表示数值范围的指标留空，并记录在 `overflow_features`。

每条 CSV 记录对应“窗口 × 通道”，保存来源、时间列/单位/原始起点、
输入通道、模长轴、窗口/步长、无效值策略、频谱设置、0 起始且包含两端的
原始行号、相对起止时间、完整窗标识和有效值计数。频域不满足条件时，
时域仍保留，`spectral_status` 和 `spectral_message` 记录原因，频域指标为空。
`disabled` 表示用户关闭了窗口频域特征；片段频谱仍可独立查看。

## FFT / Welch 的条件与定义

“所选片段的 FFT 与 Welch PSD”按原始样本行选择范围，包含两端。
默认查看前 256 行；独立于滑动窗口计算，可选已计算的模长通道。
提交特征表单后，片段频谱使用该次提交的频谱参数。

- 至少两个样本；信号与时间均须有限，时间严格递增。
  NaN/Inf 不会被删除后再做 FFT；重复、逆序、无效时间戳均拒绝计算。
- 用有效相邻间隔中位数估计 `fs`。要求每个间隔的
  `abs(Δt / median(Δt) − 1)` 不超过相对容差，默认 `1e-6`，上限 `0.05`。
  容差为 0 表示对精确原始间隔要求完全相等，直接浮点时间可能产生微小误差。
  放宽容差就是接受近似等间隔假设；报告显示实测 `max_relative_jitter`。
  不插值或重采样，拒绝原因不是故障诊断。
- 默认先去除整个所选片段的均值；时域统计仍使用原始信号。
  关闭后频谱保留 DC；Welch 不额外逐段去趋势。
- FFT 为实数单边幅值谱，矩形窗，`abs(rfft)/N`，除 DC 与偶数长度的
  Nyquist 外乘 2。纵轴单位同输入信号，分辨率 `fs/N`。
- Welch PSD 使用显式周期 Hann，分段长度取 `min(用户配置, N)`，
  重叠数为分段长度的一半向下取整、均值平均、`density` 归一化。
  PSD 纵轴为信号单位²/Hz，频率格点间隔为 `fs/nperseg`。
- `dominant_frequency_hz` 取非 DC FFT 最大幅值的频率格点；数值噪声
  级的非 DC 分量不作为主频。零信号或常数去均值后主频、谱质心为空。
- `psd_integral = sum(PSD) × Δf`，单位为信号单位²，使用完整单边离散
  频率格点求和（包含 DC/Nyquist），不使用会减半端点权重的梯形积分。
- `spectral_energy = psd_integral × N/fs`，是基于 Welch 的能量估计，
  单位为信号单位²·s；`N/fs` 是频谱时长约定，和首尾时间差 `(N−1)/fs`
  不同。它不是机械能，也不保证等于原始非平稳信号平方和积分。
- `spectral_centroid_hz = sum(f × PSD) / sum(PSD)`，使用 Welch 功率权重，
  包含 DC；功率为零时为空。所有频域指标描述预处理后的信号。

短窗口频率分辨率较差；非整数周期会产生谱泄漏，主频是格点估计，
不是精确参数拟合。Welch 分段长度和去均值设置会改变非平稳信号的积分。
高于 Nyquist 的真实频率无法从这些采样唯一恢复，系统不判断真实信号是否混叠。
算法约定参考 SciPy 官方 [rfft 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.fft.rfft.html)
与 [Welch 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.welch.html)。

实际已知信号验证及复现命令见 [Phase 2 结果](../examples/PHASE2_RESULT.md)。

## 异常检测操作

1. 选择分析通道，切到“异常检测”。MAD 对每个原始通道分别评分；
   IF 把同一原始行的所选通道组成一个多变量向量，当前不使用窗口特征。
2. 指定**参考样本行**和**检测样本行**区间，两端均包含，区间不能重叠。
   默认前段用于参考、后段用于检测。参考应来自合适工况；程序无法保证其正常。
   若有多次独立事件，按完整事件分割，避免同一事件进入两组。
3. 设置相应方法的参数，点击“运行检测”。修改表单后需重新提交；
   显示/导出均使用最后一次成功提交的配置。改变侧栏间隔倍数后也需重新运行
   检测，才会更新候选区间合并规则。
4. 检查参考基准和评分状态：被跳过的记录不是“已判断正常”。
5. 选择候选区间查看局部原始信号、分数及阈值；青色虚线/阴影为统计候选，
   原有质量标记和断线仍保留。选择“自选样本范围”可手动探索。
   “信号浏览”也显示最近一次成功检测的候选。
6. 下载候选区间 CSV、逐行分数 CSV、检测配置 JSON。更换来源、时间映射、
   单位或通道后旧结果清除，需要重新计算。

### MAD 参数与特殊分布

参考有效样本至少 5 个/通道。训练中位数为 m，训练 MAD 为 median(abs(x−m))，
鲁棒尺度 s = max(1.4826×MAD, 用户指定最小尺度)，分数为 abs(x−m)/s。
严格大于阈值才标候选，默认阈值 3.5。
因子 1.4826 是常用正态分布尺度约定，不保证任意分布下的显著性或误报概率。

默认最小尺度 0；MAD=0 时该通道全部记录为 `zero_mad`，分数为空。
整数/量化信号或多数读数相同都可能造成此状态。若已知测量分辨率，
可明确设置大于 0 的最小尺度抑制微小变化。尺度单位同通道；
不同量纲或分辨率的通道最好分批检测，不把一个数值随意用于全部传感器。
本示例的尺度 1 是原始整数读数的测试约定，不是适用于所有机器人的最佳阈值。

该版本的 MAD 使用固定参考基准，不是滚动 MAD；工况变化、漂移或参考区间
分布不匹配可能产生较多候选，不能据此推断硬件故障。

### Isolation Forest 参数与分数

参考区间至少 16 个完整有限行；缺失任一所选通道或时间戳就不参与拟合。
每通道的最大绝对值缩放只在参考区间计算；全零列的除数取 1。
缩放是数值处理，不是从检测数据重新估计标准化参数。
scikit-learn 内部使用 float32，极端数值或精度差异会影响结果；
无法转换到有效范围的检测行被标为 `numeric_range`，不裁剪或补值。

树数默认 100（10–300），每棵树样本上限默认 256（16–1024，实际不超过
有效参考行数），随机种子默认 42，单个 CPU worker。
`contamination=auto` 使用库的自动阈值；显式数值须在 (0, 0.5]，
它确定**参考分布上的阈值**，不要求检测集恰好出现相同比例的候选。
全部参考通道都是常数时禁用评分（`constant_baseline`）；
单个常数轴在多变量模型里也可能无法检测轴上的新变化。

输出分数为 `−decision_function`，严格大于 0 为候选，越大越异常。
分数不是故障概率，不能与 MAD 分数作同量纲比较。
定义参考 [scikit-learn IsolationForest 官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.IsolationForest.html)。

### 区间、状态与导出

只把同方法/通道的相邻候选原始行合并；正常行、未评分行、时间无效、
重复/逆序、大/短间隔均打断。间隔基准取参考区间的有效相邻正间隔中位数，
阈值倍数保存于检测配置；没有有效基准时至少要求时间严格递增。
MAD 的区间属于一个通道，IF 的 `__multivariate__` 属于所选通道的联合向量，
不能根据 IF 联合候选归因到某一轴。

| 状态 | 含义 |
| --- | --- |
| ok | 已有效评分；is_candidate 表示是否超过实际阈值 |
| invalid_signal / invalid_timestamp | 信号或时间无效，不补值/不评分 |
| insufficient_fit | 有效参考样本不足 |
| zero_mad | MAD 与显式最小尺度均为零 |
| constant_baseline | IF 的全部参考通道为常数 |
| numeric_range | 拟合尺度或检测分数/输入超出可表示数值范围 |

候选 CSV 保存来源、时间/通道映射、拟合/检测行范围、方法参数、候选行边界、
起止相对时间、峰值分数/原始行、阈值和规则。分数 CSV 保留每个检测行的
分数、候选标识和状态。JSON 还保存基准、版本、种子、UTC 分析时间、运行时间
和数据 SHA-256；指纹基于规范化原始表的 UTF-8 CSV，不一定等于上传文件字节指纹。
计时包含检测及结果整理，不包含 CSV 导入或文件写出；缓存命中显示原计算记录。

MAD 的“候选点记录数”按行×通道计数，同一行可重复出现；IF 按联合行计数。
常规检测页面只描述候选；“实验与报告”的固定标注任务先统一评价单位再计算指标。

## 真实机器人记录复现

当前离线样本为 [UCI Robot Execution Failures LP1](https://archive.ics.uci.edu/dataset/138/robot+execution+failures)，
88 次真实机器人力/力矩事件、每次 15 个六轴整数读数。原文件约 27 KB，
按 CC BY 4.0 单独保留来源、作者与 SHA-256，见
[数据说明](../tests/fixtures/robot_execution_failures/README.md)。它不是 IMU 数据。

Windows：

```powershell
.\.venv\Scripts\python.exe -X utf8 examples/analyze_anomalies.py
```

Linux/macOS：

```bash
.venv/bin/python examples/analyze_anomalies.py
```

输出到 `examples/generated/phase3/`，默认不覆盖。可用 `--output` 指定新目录，
明确需要重跑覆盖时用 `--overwrite`。先上传 `real_robot_lp1.csv`，选
`synthetic_time_s`、`s` 和 `Fx/Fy/Fz/Tx/Ty/Tz`；参考行 0–149，检测行 150–1319。
参考为前十个正常标签事件，其他事件完整留出。MAD 示例最小尺度为 1，
IF 使用 auto、100 棵树、样本上限 256、种子 42。

**时间轴是构造的**：原数据未提供逐点时间戳。为导入与绘图采用 0.021 s
采样步长、各事件起点相隔 1 s 的约定，不代表真实采样间隔或事件间的实际时间。
不要把该文件的频率/间隔检查结果当成真实传感器结论。
真实背景的注入副本 `injected_robot_lp1.csv` 会明确标注：第 150 行六轴值
替换为 10000；这部分是人为扰动，原始测量文件没有改动。

原标签对应整个事件类别，不是逐点异常真值。正常事件里的合法运动也可能
被简单基准判为候选；目前不据此报告真实故障准确率。
实际数量、运行时间与局限见 [Phase 3 结果](../examples/PHASE3_RESULT.md)。

## 容量与显示限制

CSV 上限为 20 MiB、100,000 个样本行、64 列。绘图最多 8 个通道、
20,000 行；超出时需缩小时间范围，不会自动抽稀。红色标记间隔问题，
紫色标记逆序，橙色标记重复，灰色标记通道无效值。
曲线在异常间隔、非递增时间、无效值或不连续原始行处断开。
最多绘制前 50 个可定位标记、显示前 500 条证据和 1000 行详情；
核心结果保存全部问题。上传数据只使用有上限和时效的会话内存缓存，
应用不会自动将上传文件保存到仓库。

窗口特征最多 50,000 条“窗口 × 通道”记录，并限制累计处理量为
20,000,000 个窗口信号值（重叠窗口重复计入）。超出时在计算前报错，
请增大步长、缩短窗口或减少通道。趋势图最多 20,000 个窗口点，
不自动抽稀；CSV 保留全部已计算记录。表单驱动计算且缓存有 TTL/条目上限。

检测最多 500,000 条评分记录；MAD 每通道逐行计入、IF 每联合行计入。
局部分数图最多 20,000 条记录，候选列表/选择框和详情显示前 1000 条，
信号图最多额外高亮 50 个候选区间，导出仍保留完整已计算结果。

生成合成演示文件的跨平台命令和标签说明见 [examples/README.md](../examples/README.md)。

## Phase 5 来源校验与常见错误

报告 schema 为 2。质量、特征和检测都记录原始值表以 UTF-8/LF CSV 规范化后的
SHA-256，以及时间列、单位、通道映射；该指纹不同于上传文件的原始字节 SHA。
输入 BOM/换行形式不同但表值和映射相同，分析身份一致。仅改变单位或通道也会
改变身份。核心调用混用旧结果、手工结果缺少来源时，报告明确要求重新计算；
网页文件、映射或核心版本改变时清除旧计算与报告，避免下载上一份数据的结果。

- 配置必须使用正确类型：数值参数不能用字符串或布尔值，开关必须是布尔值。
  通道与区间接受 list/tuple 后转为不可变 tuple；错误返回明确 ValueError。
- 文件路径读取最多上限加一字节。核心流输入须是二进制（`open(path, "rb")`），
  文本流会提示改用二进制方式；文件过大、行/列过多时明确拒绝。
- 出现“结果缺少来源或与当前数据/映射不一致”时，重新执行质量、特征和检测，
  再生成快照；不要修改旧报告指纹来绕过检查。
- wheel 只提供核心模块。运行网页请下载/克隆完整源码，从根目录启动 `app.py`；
  完整验收与 wheel 检查命令见 [VALIDATION.md](VALIDATION.md)。

[技术交底提纲](TECHNICAL_DISCLOSURE_OUTLINE.md)，实际结果见

## 分析报告与评价实验

“实验与报告 → 当前数据分析报告”点击生成，快照包含文件名、输入字节与规范化表
SHA-256、UTC 时间、版本、时间单位/映射、质量规则、已提交的特征和检测参数、
基准与候选证据。未执行的步骤为 null，未标注上传数据的 evaluation 也为 null。
可下载 UTF-8 JSON、Markdown、简单 HTML。HTML 可离线打开，不加载外部脚本或资源。
文本会转义，报告表格最多预览 20 条；完整特征/候选/分数 CSV 在对应页面下载。
数据、映射、间隔阈值变化或重新提交特征/检测会清除旧快照，请重新生成。
尚未提交的表单修改不改变结果，报告仍记录上次实际计算参数。

“内置真实记录实验”使用仓库 LP1 fixture，**独立于当前上传文件**，点击按钮运行：

| 任务 | 参考 / 留出 | 真值 | 预测单位 |
| --- | --- | --- | --- |
| real_trials | 前十个 normal 事件 / 其余 78 个完整事件 | normal 负，其他三类正 | 完整事件中任意候选点即正 |
| injected_points | 同一参考 / 11 个留出 normal 事件的 165 点 | 六轴替换行 150、225、300 为正，其余为非注入背景 | 任意候选通道使该点为正 |

扰动副本的三个位置六轴替换为 10000，原始值及原始 trial_id/sample_index 会记录。
原始测量不修改；真实事件标签不复制成逐点故障标签。注入任务的阴性是“没有人为替换”，
其 FPR 表示非注入背景告警，不可解释为自然故障误诊率。这两项任务复用正常背景，
不代表两套独立数据集。另执行真实测量副本的重复/逆序/大间隔检查、解析常数/正弦校验，
以及真实数据每个完整事件一个 15 点窗口的六通道时域特征；不计算真实物理频率。

固定比较 MAD 3.5、scale_floor=1，与 IF auto、100 棵树、max_samples=256、
random_state=42（参考实际 150 行）。这组参数未根据 Phase 4 留出指标调优。
参考正常事件使用标签选择，是正常参考学习假设。六轴共用；MAD 先将行×通道合并为点。
点的全部选定通道须可评分，事件的全部原始点须可评分，才参与指标；排除原因与覆盖率另报。

| 指标 | 定义 |
| --- | --- |
| precision | TP / (TP + FP) |
| recall | TP / (TP + FN) |
| F1 | 2TP / (2TP + FP + FN) |
| FPR | FP / (FP + TN) |

TP/FP/TN/FN 基于该任务的同一评价单位；分母为零写 null，不强行记 0。
计时包含拟合/评分/合并/指纹，评价单独计时；不包含模块导入、报告渲染或文件写出。
界面会话缓存 TTL 600 秒、最多两次实验，命中时显示原实际运行时间戳。

完整文件导出：

```powershell
.\.venv\Scripts\python.exe -X utf8 examples/run_experiments.py
```

```bash
.venv/bin/python examples/run_experiments.py
```

默认输出 `examples/generated/phase4/` 的 23 个文件：三种格式报告、metrics.csv、
predictions.csv、splits.json、原样/正常背景/扰动/质量探针 CSV、real_features.csv，
以及两项任务×两种方法各自的候选 CSV、逐行分数 CSV、配置 JSON。
默认发现任一目标文件已存在即拒绝写入；用 `--output 新目录` 保留每次记录，
只有明确需要覆盖时使用 `--overwrite`。`--input` 可指定符合 LP1 结构的文件，
报告记录其真实 SHA 与是否为已核对原始 fixture；不把其他文件自动认作官方原始数据。
